# Deploy without running anything locally

1. Create a free database at https://neon.tech and copy the connection string.
2. Put this project in your GitHub repo (upload all files).
3. At https://render.com choose New > Blueprint, pick the repo.
4. Set DATABASE_URL to the Neon string. Set APP_URL to the URL Render gives you (https://your-name.onrender.com).
5. Deploy. Tables and the first admin account are created automatically.
6. Log in: admin@maknazulirfan.org / ChangeMe_Admin_2026! then change the password.
